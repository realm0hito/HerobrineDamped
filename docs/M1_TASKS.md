# Milestone 1 — task breakdown (implementation order)

Goal: window + Vulkan 1.3 bootstrap, compute → storage image → blit → swapchain, 256³ dense grid traced with
integer Amanatides–Woo DDA, fly camera, step heatmap, cimgui frame timings. Layouts: `PLAN.md` §3.7–3.9.

Each task is **one or a few small commits**. A task is done when: it builds on Linux (gcc + clang) and
Windows (MSVC + clang-cl, at least one checked per task, both by end of M1), runs, and the validation layer is
silent (sync validation from T6 onward). Hours are rough.

| # | Task | Done when | h |
|---|---|---|---|
| T0 ✓ | **Skeleton.** Root `CMakeLists.txt`, `CMakePresets.json`, `cmake/CompilerOptions.cmake`, empty `src/main.c`, `.clang-format`. | `cmake --preset linux-clang-debug && cmake --build --preset linux-clang-debug` produces `engine` that returns 0; same on Windows presets. | 2 |
| T1 ✓ | **Submodules.** Add all of PLAN §10 at the pinned commits (`--recursive` for cimgui). `cmake/Dependencies.cmake` with `SYSTEM EXCLUDE_FROM_ALL`, options off (GLFW examples/tests/docs/install, cglm tests), `volk` + `Vulkan::Headers`, `vma_impl.cpp`, `hd_imgui` target. | Engine links every library; a dummy call into each compiles; third-party warnings don't appear. | 3 |

| T4 | **Instance + device.** `vk_ctx.c`: instance 1.3 + GLFW extensions + debug utils + validation (CLI `--validation=off|on|sync|gpuav`, default `on` in Debug) using `VkValidationFeaturesEXT`; messenger routes to log and **counts** messages; physical device pick (required feature chain from PLAN §11, discrete preferred, `--gpu=N` override, prints missing features); one graphics+compute+present queue; device create with the feature chain; `volkLoadDevice`; VMA with `BUFFER_DEVICE_ADDRESS_BIT` + `vmaImportVulkanFunctionsFromVolk`; `vk_debug.c` name helper (`gpu_name(obj, type, fmt, ...)`, compiled out in Release). | Selected GPU + driver printed; validation count 0 at shutdown; teardown order correct (no leak reports). | 5 |

| T6 | **Frame loop + sync helpers.** `vk_frame.c`: 2 frame slots (cmd pool+buffer, fence, acquire semaphore, frame arena mark); `vk_sync.c`: `barrier_image`, `barrier_buffer`, `barrier_global` wrappers over `vkCmdPipelineBarrier2`, layout helpers; first visible output = `vkCmdClearColorImage` on the swapchain (TRANSFER_DST) → PRESENT. Debug-utils labels per pass. | Animated clear colour; sync-validation run clean for 60 s. | 3 |
| T7 | **Shader pipeline.** `cmake/Shaders.cmake` (`hd_add_shaders`, glslc with `-MD` depfiles, output next to exe), `shaders/shared/gpu_types.h` (C/GLSL shim, `GpuFrame`, `GpuPush`), `shaders/lib/frame.glsl`; `vk_bindless.c` (one set: storage images[64], sampled images[64], samplers[8], UPDATE_AFTER_BIND + PARTIALLY_BOUND, one pipeline layout with 128 B push constants); `vk_pipeline.c` (load `.spv`, create compute pipeline, debug name). | Editing an included `.glsl` rebuilds dependent `.spv` only; C `_Static_assert`s on struct sizes pass. | 4 |
| T8 | **First compute pixels.** RGBA16F color storage image (GENERAL, bindless index), `test_gradient.comp` writes UV + time, blit color → swapchain (linear filter), `GpuFrame` per slot in host-visible buffer via BDA. Format feature checks from PLAN §11. | Gradient on screen, correct after resize; sRGB looks right (mid-grey ramp check). | 3 |
| T9 | **GPU timing.** `vk_timing.c`: timestamp query pool per slot (`hostQueryReset`), `timing_begin/end(cmd, "name")`, results read after fence wait (no stalls), ns via `timestampPeriod`; CPU frame/update/record times; rolling 240-frame history (fixed arrays). | Numbers printed once/s; no `VK_QUERY_RESULT_WAIT_BIT`. | 2 |
| T10 | **cimgui.** `hd_imgui` init: GLFW backend (`InitForVulkan`, callbacks installed), Vulkan backend (`ApiVersion=1_3`, `UseDynamicRendering`, `PipelineInfoMain.PipelineRenderingCreateInfo` with the swapchain format, `DescriptorPoolSize`), `ImGui_ImplVulkan_SetMinImageCount` on recreate; UI pass with dynamic rendering `loadOp=LOAD` after blit. Panel: FPS, CPU ms, GPU ms per pass + plot lines, present mode combo, render-scale slider, validation message count. Input routing: UI wants mouse → camera ignores it. | Panel usable; resize & present-mode change keep UI correct; validation clean. | 4 |
| T11 | **Fly camera.** `camera.c`: `int32 cell[3] + float frac[3]`, yaw/pitch, WASD/QE, shift/ctrl speed multipliers, scroll = speed, RMB/Tab capture; renormalise frac → cell; render origin = camera chunk × 64; `GpuFrame` basis vectors + `tan_half_fov`, `pixel_angle`. Teleport field in UI (world voxel coords). | Smooth flight; teleport to `(2e9, 0, 2e9)` shows no jitter in UI-reported render-space position. | 3 |
| T12 | **Dense grid.** `dense_grid.c`: 256³ u8 materials packed 4/u32; `scene_fn.c` (sphere, value-noise terraced heightfield, pillars, thin 1-voxel walls; same function will feed M2); material table (16 entries, `GpuMaterial`); `vk_upload.c` staging ring (persistent mapped, per-slot region, `upload_buffer(dst, off, src, size)` → batched `vkCmdCopyBuffer2`), one-time upload + barrier. Grid origin set in world coords (UI-movable, to test far-from-origin placement). | Upload once, memory stats in UI (16 MiB), validation clean. | 4 |
| T13 | **TRACE_DENSE.** `trace_dense.comp` 8×8 workgroups: primary ray from `GpuFrame`; slab clip to grid AABB in render space; integer DDA per PLAN §4 rules 1–2 (plane-derived t, exact entry face); write vis RG32UI (t, local coords, face) + optional steps R32UI; max-iteration cap. `shaders/lib/dda.glsl` holds the reusable stepping code. | Correct silhouette of thin walls at grazing angles (no leaks/holes) from inside and outside the grid; camera inside a solid voxel renders black, not garbage. | 6 |
| T14 | **RESOLVE + debug views.** `resolve.comp`: decode vis, exact voxel recovery (§3.7), material fetch, face normal, Lambert sun + hemispherical ambient + per-voxel hash variation, simple tonemap; views: shaded / normal / depth / steps heatmap (turbo ramp, slider for max, legend in panel) / raw vis / chunk-boundary overlay / "budget exceeded". | Each view selectable; heatmap brightens at grazing angles and around silhouettes as expected. | 4 |
| T15 | **Resize & render scale.** Recreate vis/steps/color on resize or scale change (wait idle, re-register bindless indices); blit scales to swapchain. | 0.5–2.0 scale works; validation clean while dragging. | 2 |
| T16 | **M1 sign-off.** Measure on your GPU(s): TRACE/RESOLVE ms at 1080p for 3 fixed views (stored as named camera bookmarks); 60 s flight with sync validation; Windows MSVC + clang-cl builds; alloc counter = 0/frame after warm-up; `docs/notes/M1.md` with numbers + screenshots. | All M1 acceptance criteria in PLAN §7 met. | 3 |
| (opt) | Shader hot reload (F5 / file mtime poll; recreate pipeline after `vkDeviceWaitIdle`). | Edit `resolve.comp` while running → updated image. | 3 |
| (opt) | Headless mode `--frames N --screenshot out.png` (no swapchain; offscreen color) for lavapipe CI. | Deterministic image on lavapipe. | 4 |

Total ≈ 55 h (+7 h optional).
